# Dark Magic Studios — Landing Page

The official marketing site for Dark Magic Studios, an independent software studio focused on tools, games, and developer products. Built with Next.js (App Router), TypeScript, and Tailwind CSS, the page presents the studio's work and identity through a dark, minimalist design derived from the Dark Magic Studios visual brand — deep violets, electric cyan-blue accents, and the Cinzel serif wordmark.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
